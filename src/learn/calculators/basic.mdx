### The Core Keypad: Numbers and Basic Operations

Every basic calculator has a **standard set of keys**. Understanding what each one does is the first step to proficiency.

#### Essential Keys

| Key | Function | When to Use |
|-----|----------|-------------|
| **0-9, .** | Number input | Enter values for calculations |
| **+, -, ×, ÷** | Operations | Tell calculator what math to perform |
| **=** | Execute | Get the final result |

#### Clear Functions

| Key | What It Does | Best For |
|-----|--------------|----------|
| **C (Clear)** | Deletes last entry | Correcting simple typos |
| **AC (All Clear)** | Resets everything | Starting completely new problems |

> **Pro Tip**: Use **C** for quick corrections, **AC** when you want to start fresh

### The Memory Function: Your Calculator's Notepad

The memory function is a **powerful tool for multi-step calculations**, acting as a temporary storage space for numbers.

#### Memory Keys

| Key | Function | Example Use |
|-----|----------|-------------|
| **MC** | Memory Clear | Erase stored number |
| **MR** | Memory Recall | Display stored number |
| **M+** | Memory Plus | Add current number to memory |
| **M-** | Memory Minus | Subtract current number from memory |

**How M+ works**: If memory is empty, it stores the current number. If memory has a value, it adds to that total.

### Special Function Keys
*   **% (Percentage):** Calculates percentages. Its behaviour can vary, but commonly, entering `200 × 10%` will calculate 10% of 200 (resulting in 20).
*   **+/- (Plus/Minus):** Changes the sign of the displayed number from positive to negative, or vice versa.

### Why Order Matters: PEMDAS/BODMAS
A fundamental concept that distinguishes a good calculator user from a novice is understanding that calculators don't always perform operations in the order you type them. They follow a strict rule known as the **order of operations**.

The standard order is often remembered by the acronym **PEMDAS** (Parentheses, Exponents, Multiplication and Division, Addition and Subtraction) or **BODMAS** (Brackets, Orders, Division and Multiplication, Addition and Subtraction).

**What it means:**
1.  **P**arentheses (or **B**rackets): Calculations inside parentheses are always done first.
2.  **E**xponents (or **O**rders): Next, any exponents (like squares or square roots) are calculated.
3.  **M**ultiplication and **D**ivision: These operations have equal priority and are performed from left to right.
4.  **A**ddition and **S**ubtraction: These operations have equal priority and are performed from left to right.

### Examples of Order of Operations

**Example 1: The Common Mistake**
Calculate: `5 + 3 × 2`
*   **Incorrect Approach (left to right):** `5 + 3 = 8`, then `8 × 2 = 16`.
*   **Correct Approach (PEMDAS):** Multiplication comes before addition. `3 × 2 = 6`, then `5 + 6 = 11`.
*   A good basic calculator will correctly give the answer **11**.

**Example 2: Using Parentheses**
Calculate: `(5 + 3) × 2`
*   Here, parentheses force the addition to happen first: `5 + 3 = 8`.
*   Then, the multiplication: `8 × 2 = 16`.
*   By using parentheses, you change the result to **16**.

### How to Perform a Chain Calculation
Let's walk through a practical example that uses multiple operations and the memory function.

**Scenario:** You are shopping. You buy a item for £18.50, another for £12.99, and there is a 10% discount on the total. You then need to add a 5% sales tax. What is the final price?

**Method 1: Using the Equals Key and Memory**
1.  **Calculate the subtotal:** `18.50 + 12.99 = ` → **31.49**
2.  **Store the subtotal in memory:** Press `M+`. The calculator now has 31.49 stored.
3.  **Calculate the discount:** Recall the memory with `MR`, then `× 10 % = ` → **3.149** (the discount amount).
4.  **Calculate the price after discount:** Recall the subtotal again with `MR`, then `- 3.15 = ` → **28.34** (rounding the discount).
5.  **Calculate the tax:** With 28.34 on screen, `× 5 % = ` → **1.417** (the tax amount).
6.  **Calculate the final total:** `28.34 + 1.42 = ` → **£29.76**

**Method 2: A Direct Chain (if your calculator allows)**
A more advanced calculator might let you input: `18.50 + 12.99 - 10% + 5% = `, but understanding the memory method ensures accuracy on any device.

### Common Mistakes to Avoid
*   **Ignoring Order of Operations:** Assuming `2 + 3 × 4` equals 20 instead of 14.
*   **Forgetting to Clear Memory:** Starting a new problem with a number still in memory from a previous calculation, which can throw off your results.
*   **Misusing the Percent Key:** Not understanding that `100 + 10%` typically means "add 10% of 100 to 100," resulting in 110.
*   **Not Using Parentheses for Clarity:** When in doubt, use parentheses to group calculations and ensure they happen in the order you intend.

### Frequently Asked Questions (FAQ)

**Q: What is the difference between a basic calculator and a scientific calculator?**
A: A basic calculator handles addition, subtraction, multiplication, division, percentages, and square roots. A scientific calculator includes these plus advanced functions like trigonometry, logarithms, exponents, and statistical calculations, and it has a more sophisticated order of operations logic.

**Q: How does the percentage (%) button work on a basic calculator?**
A: It typically calculates a percentage of the number currently on the screen. For example, to find 15% of 200, you would enter `200 × 15 %`. The result will be 30. To add a percentage, you would use `200 + 15%` to get 230.

**Q: Why did my calculator give me a different answer than I expected?**
A: The most likely cause is the order of operations. Your calculator follows PEMDAS/BODMAS rules. If you typed `5 + 3 × 2` and expected 16, the calculator correctly gave 11 because it multiplied before adding. Use parentheses `(5 + 3) × 2` to get 16.

**Q: When should I use the MC (Memory Clear) button?**
A: You should press `MC` at the beginning of any new calculation session to ensure no old values are stored in memory. It's a good habit to clear the memory before starting a fresh problem.

**Q: Can I use the keyboard with an online basic calculator?**
A: Yes, most online calculators support full keyboard entry. You can use the number keys, `+`, `-`, `*`, `/`, `Enter` for equals, and `Delete` for clear. This is often faster than clicking buttons with a mouse.
