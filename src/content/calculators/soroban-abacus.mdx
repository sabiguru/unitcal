## How to Use This Calculator - Soroban Abacus
Clear the abacus by moving all beads away from the center beam.

Set a number by clicking beads or entering a value in the input field.

Manipulate beads to perform calculations:
- Move upper bead down to the beam = add 5
- Move lower beads up to the beam = add 1 each
- Reverse movements to subtract

Read the result from the digital display. Each rod represents a place value (units, tens, hundreds, etc.).

Use the Clear button to reset all rods to zero.

## The Core Principle: Bead Values and Place Value

The soroban is a 1:4 abacus—one upper bead (heaven bead) worth 5, and four lower beads (earth beads) worth 1 each.

**Reading a rod:**
- Upper bead touching beam: add 5
- Each lower bead touching beam: add 1
- Maximum per rod: 5 + 4 = 9

**Place value:**
Each rod represents a decimal place. From right to left: units, tens, hundreds, thousands, etc.

**Example: The number 7 on one rod**
- Move upper bead down (5)
- Move two lower beads up (2)
- Total: 5 + 2 = 7

**Complement rules:**
To add efficiently, use complements:
- Complement to 5: if adding 3 and rod shows 4, add 5, subtract 2
- Complement to 10: if adding 8 and rod shows 4, add 10 (carry), subtract 2

These rules enable rapid calculation without counting individual beads.

## How to Calculate on a Soroban

**Addition example: 47 + 68**

**Step 1: Set 47**
- Tens rod: 4 lower beads up (4)
- Units rod: upper bead down + 2 lower beads up (5 + 2 = 7)

**Step 2: Add 60 (6 tens)**
- Tens: 4 + 6 = 10 → carry to hundreds
- Clear tens rod, add 1 to hundreds rod
- Hundreds shows 1, Tens shows 0

**Step 3: Add 8 to units**
- Units: 7 + 8 = 15 → need to carry
- Use complement: +8 = +10 - 2
- Add 1 to tens rod (now 1)
- Subtract 2 from units: 7 - 2 = 5
- Units shows 5

**Result: 115**
Hundreds: 1, Tens: 1, Units: 5

**Subtraction example: 53 - 28**

**Step 1: Set 53**
- Tens: upper bead down (5)
- Units: 3 lower beads up (3)

**Step 2: Subtract 20 (2 tens)**
- Tens: 5 - 2 = 3
- Move upper bead up, move 3 lower beads up
- Tens shows 3

**Step 3: Subtract 8 from units**
- Units: 3 - 8 = can't directly subtract
- Use complement: -8 = -10 + 2
- Borrow from tens: tens becomes 2
- Add 2 to units: 3 + 2 = 5
- Units shows 5

**Result: 25**

## Scenarios People Actually Run Into

**The complement confusion.** When adding 7 to 8, beginners want to count beads. The complement method (+7 = +10 - 3) is faster once learned.

**The carry cascade.** 999 + 1 requires carrying through all rods. Practice carries systematically.

**The reading direction.** Read left to right (high to low place value), just like regular numbers.

**The decimal placement.** For decimals, mentally designate a rod as the decimal point. Operations work identically.

**The speed plateau.** Initial progress is fast; advanced speed requires extensive drill on complements and finger technique.

## Trade-Offs and Decisions People Underestimate

**Physical versus mental soroban.** Physical practice builds the foundation; mental visualization (anzan) is the ultimate goal.

**Speed versus accuracy.** Pushing for speed increases errors. Build accuracy first, then gradually increase pace.

**1:4 versus 2:5.** The soroban (1:4) is streamlined for speed. The Chinese suanpan (2:5) offers more intermediate states. Choose based on your goals.

**Complement mastery.** Complements feel awkward initially but are essential for speed. Invest time in drilling them.

**Regular practice.** Skills decay without practice. Even 10 minutes daily maintains and builds ability.

## Common Mistakes and How to Recover

**Not clearing properly.** Start every calculation with a cleared abacus. Residual beads cause errors.

**Forgetting carries.** When a rod exceeds 9, carry to the next rod. Missing carries produces wrong answers.

**Using wrong complement.** Complement to 5 and complement to 10 are different operations. Know which to use when.

**Counting beads individually.** This defeats the purpose. Learn to recognize patterns and use complements.

**Neglecting finger technique.** Proper finger movements enable speed. Thumb pushes up; index finger pushes down.

## How This Calculator Works

**Bead value calculation:**
```
for each rod:
  upperValue = upperBead × 5 (if touching beam)
  lowerValue = count(lowerBeads touching beam) × 1
  rodValue = upperValue + lowerValue

totalValue = sum(rodValue × 10^position)
```

**Setting a number:**
```
for each digit (right to left):
  if digit >= 5:
    move upper bead down
    remainder = digit - 5
  else:
    remainder = digit
  move 'remainder' lower beads up
```

**Addition with complement:**
```
if simpleAddition possible (result ≤ 9):
  add directly
else if complement to 5 works:
  subtract complement from 5
  add 5 (move upper bead)
else:
  subtract complement from 10
  carry 1 to next rod
```

**Display synchronization:**
```
Read all rod values
Combine into decimal number
Update digital display
```

## FAQs

**What is a 1:4 abacus?**

One upper bead (value 5) and four lower beads (value 1 each) per rod. This streamlined design is optimized for decimal calculations.

**How do I clear the soroban?**

Move all upper beads up (away from beam) and all lower beads down (away from beam). Display should show 0.

**Can I use this for decimals?**

Yes. Designate a rod as the decimal point. Rods to its right are tenths, hundredths, etc. Calculation rules remain unchanged.

**Why use a soroban instead of a calculator?**

The soroban builds number intuition, concentration, and mental calculation skills that calculators don't develop. It's cognitive training, not just answer-finding.

**Is this suitable for children?**

Yes. The visual, tactile nature makes abstract math concrete. Soroban is widely used in Japanese schools for building arithmetic fluency.

**How do I learn the complement rules?**

Start with small numbers. To add 6 when you have 4: +6 = +10 - 4 (carry 1, subtract 4). Practice daily until automatic.

**How long until I'm proficient?**

Basic operations: 2-4 weeks of regular practice. Advanced speed: months to years, depending on dedication.

**Can I compete with this skill?**

Yes. Soroban and mental calculation competitions exist worldwide, testing speed and accuracy at various levels.
