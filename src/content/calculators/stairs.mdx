## How to Use This Calculator

Enter your Total Rise—the vertical distance between finished floors.

Enter your Target Riser Height (default: 7.5 inches or 190mm).

Enter your desired Tread Depth (default: 10 inches or 250mm).

Click "Calculate" to see results. The output displays:
- Number of risers and treads
- Exact riser height
- Total horizontal run
- Stringer length (using Pythagorean theorem)
- Comfort check (2R + T formula)
- Code compliance status

## The Core Principle: Safe and Comfortable Stairs

Stairs must balance safety, comfort, and code compliance. Key dimensions are riser height (vertical) and tread depth (horizontal).

**The comfort formula:**
2 × Riser + Tread ≈ 24-25 inches (610-635mm)

This formula, developed over centuries, produces stairs that feel natural to climb.

**Typical code limits (residential):**
- Maximum riser: 7.75" (196mm)
- Minimum tread: 10" (254mm)
- Maximum variation: 3/8" (9mm) between any two risers

**Key relationships:**
- Treads = Risers - 1 (the top floor is the last "tread")
- Total Run = Treads × Tread Depth
- Stringer Length = √(Rise² + Run²)

## How to Calculate Stair Dimensions

**Example: 106-inch total rise**

**Step 1: Determine number of risers**
Target riser: 7.5 inches
106 / 7.5 = 14.13 → round up to 15 risers

**Step 2: Calculate exact riser height**
106 / 15 = 7.07 inches per riser (within code)

**Step 3: Calculate number of treads**
Treads = 15 - 1 = 14 treads

**Step 4: Calculate total run**
14 treads × 10 inches = 140 inches

**Step 5: Calculate stringer length**
√(106² + 140²) = √(11,236 + 19,600) = √30,836 = 175.6 inches

**Step 6: Verify comfort**
2 × 7.07 + 10 = 24.14 inches ✓ (within 24-25 target)

## Scenarios People Actually Run Into

**The "just miss" problem.** 7.8-inch risers exceed code by a small margin. Recalculate with one more riser to get 7.3 inches—within code.

**The finished floor surprise.** You measured to subfloor, but finished flooring adds 3/4 inch to total rise. Measure finished-to-finished.

**The headroom constraint.** Code requires 6'8" minimum headroom. Long stair runs may require design changes to maintain clearance.

**The comfort failure.** Calculator shows compliant stairs, but comfort formula gives 27—too shallow/long. Adjust tread depth.

**The landing requirement.** Rises over 12 feet typically require a landing. Plan for two flight runs.

## Trade-Offs and Decisions People Underestimate

**Riser consistency.** All risers must be within 3/8" of each other. One odd riser is a tripping hazard and code violation.

**Run space requirements.** Longer tread depth increases comfort but requires more horizontal space. Plan the stairwell opening accordingly.

**Stringer count.** Wider stairs need more stringers (typically every 16-18 inches) to prevent tread bounce.

**Material thickness.** Tread thickness affects stringer notch depth. Account for 1" or 1.5" treads in your design.

**Finish considerations.** Carpet adds to tread depth; account for this when planning riser height.

---

## Common Mistakes and How to Recover

**Measuring to wrong floor.** Measure finished floor to finished floor, not subfloor to subfloor.

**Rounding down risers.** Round up to ensure risers don't exceed maximum height. Shorter risers are comfortable; taller risers are dangerous and often illegal.

**Forgetting tread thickness.** The stringer notch must account for actual tread material thickness. Standard lumber is 1.5" thick.

**Ignoring headroom.** Check that ceiling openings provide adequate clearance throughout the stair run.

**Inconsistent risers.** The first or last riser is often wrong due to floor thickness errors. Measure carefully at both ends.

## How This Calculator Works

**Number of risers:**
```
targetRisers = totalRise / targetRiserHeight
actualRisers = ceiling(targetRisers)

// Ensure riser doesn't exceed maximum
while (totalRise / actualRisers > maxRiserHeight):
  actualRisers++
```

**Exact riser height:**
```
exactRiser = totalRise / actualRisers
```

**Number of treads:**
```
treads = risers - 1
```

**Total run:**
```
totalRun = treads × treadDepth
```

**Stringer length:**
```
stringerLength = sqrt(totalRise² + totalRun²)
```

**Comfort check:**
```
comfortValue = 2 × exactRiser + treadDepth
comfortable = (comfortValue >= 24 && comfortValue &lt;= 25)
```

All calculations happen locally in your browser.

## FAQs

**What is total rise?**

The vertical distance between finished floor surfaces—from the lower floor to the upper floor.

**Why round up the number of risers?**

Rounding up ensures risers don't exceed maximum height (typically 7.75"). Shorter risers are acceptable; taller risers violate code.

**Can I change the tread depth?**

Yes. Adjust tread depth to fit available horizontal space. The calculator updates total run and comfort score.

**Does this work for deck stairs?**

Yes. The same calculations apply. For open-riser deck stairs, riser height still matters for safety.

**How accurate is the stringer length?**

Mathematically precise using the Pythagorean theorem. Account for tread thickness when cutting notches.

**What if my stairs fail the comfort check?**

Adjust riser height (try 7" instead of 7.5") or tread depth (try 11" instead of 10") and recalculate.

**Do I need a landing?**

Most codes require landings for rises over 12 feet (144"). Check local requirements.

**Can I use metric measurements?**

Yes. Enter in millimeters or centimeters. The calculator applies metric code limits (max riser ~197mm).
