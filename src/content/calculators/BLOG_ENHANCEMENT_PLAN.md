**Location:** `/home/oyinkuro/projects/myWritingProfile/`

**Key Requirements:**
- British English spelling (analyse, behaviour, realised, colour)
- No contractions (use "cannot" not "can't")
- Passive voice for technical content
- Formal verbs (employed, investigated, demonstrated, ensures, enables)
- Moderate to long sentences (20-30 words average)
- Sequential markers (Firstly, Secondly, In the first stage)
- No exclamation marks or emojis
- Oxford comma NOT used

## Structure Variation Templates

To avoid templated patterns, each batch will use different section arrangements:

### Template A - Problem-First
1. Real-World Challenge (with current data)
2. How This Calculator Addresses It
3. Step-by-Step Usage
4. Worked Examples with Live Data
5. Common Pitfalls
6. Related Calculations
7. Sources

### Template B - Data-Led
1. Current Statistics and Trends
2. Why These Numbers Matter
3. Calculator Walkthrough
4. Case Studies (multi-country comparison)
5. Limitations and Considerations
6. Further Reading
7. Sources

### Template C - Scenario-Based
1. Three Real Scenarios (different contexts)
2. The Mathematics Explained
3. Using the Calculator
4. Interpreting Results
5. Decision Framework
6. Related Tools
7. Sources

### Template D - Historical + Current
1. How This Has Changed Over Time
2. Current State (with 2025-2026 data)
3. Calculator Mechanics
4. Practical Applications
5. Regional Variations
6. Expert Considerations
7. Sources

### Template E - Comparison-Driven
1. Method A vs Method B (or Country A vs B)
2. When Each Applies
3. Calculator Features
4. Worked Comparison Examples
5. Edge Cases
6. Professional Tips
7. Sources
