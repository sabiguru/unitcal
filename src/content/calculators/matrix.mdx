### Step-by-Step Example
**Scenario**: Find the inverse of a 2×2 matrix.

**Inputs**:
- Matrix A: `[[4, 7], [2, 6]]`

**Calculation Process**:
1. **Compute determinant**: `det = (4)(6) – (7)(2) = 24 – 14 = 10`
2. **Apply inverse formula**:  
   `A⁻¹ = (1/10) × [[6, -7], [-2, 4]]`
3. **Simplify**:  
   `A⁻¹ = [[0.6, -0.7], [-0.2, 0.4]]`

**Verification**:  
`A × A⁻¹ = [[4×0.6 + 7×(-0.2), 4×(-0.7) + 7×0.4], [2×0.6 + 6×(-0.2), 2×(-0.7) + 6×0.4]] = [[1, 0], [0, 1]] = I`

This confirms the inverse is correct.

<TabPanel title="FAQ">
### How do I enter a matrix?
Use double brackets with rows separated by commas:  
`[[1, 2, 3], [4, 5, 6]]` for a 2×3 matrix.  
Decimals and fractions are accepted (e.g., `0.5` or `1/2`).

### What if my matrix isn’t square?
- **Multiplication**: Works if inner dimensions match (e.g., 2×3 × 3×4 = 2×4)  
- **Determinant/Inverse**: Only defined for square matrices (n×n)  
- **Ax = b**: A must be square for inverse method; otherwise, use elimination

### Why is my matrix not invertible?
A matrix is **singular** (non-invertible) if its **determinant is zero**. This means its rows/columns are linearly dependent, and the system Ax = b either has no solution or infinitely many.

### Can I solve systems with more equations than unknowns?
Yes. The calculator uses **least-squares** or **Gaussian elimination** to find solutions or indicate inconsistency. Overdetermined systems may have no exact solution.

### How accurate are the results?
The calculator uses exact arithmetic for fractions and high-precision decimals. For large matrices, rounding may occur, but results are mathematically sound.

### What’s the difference between rank and determinant?
- **Determinant**: Scalar value for square matrices; zero = singular  
- **Rank**: Number of independent rows/columns; works for any matrix  
A full-rank square matrix has non-zero determinant.

### Can I use this for eigenvalues?
Not directly. Eigenvalue computation requires iterative methods (e.g., QR algorithm), which are beyond this tool’s scope. Use specialized software like MATLAB or Python’s NumPy for eigenvalues.

### Is this calculator suitable for exams?
It’s perfect for **checking homework** and **learning methods**, but always understand the manual process—exams often require showing work without tools.
