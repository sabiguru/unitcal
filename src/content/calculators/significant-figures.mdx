## The Core Principle: Measurement Precision

Significant figures communicate the precision of measurements. A result should never imply more precision than the original data supports.

**What counts as significant:**
- All non-zero digits (1-9)
- Zeros between non-zero digits (sandwiched zeros)
- Trailing zeros after a decimal point
- Trailing zeros in whole numbers only if indicated (decimal point or overline)

**What doesn't count:**
- Leading zeros (0.0045 has 2 sig figs)
- Trailing zeros without decimal indication (100 has 1 sig fig by convention)

**The fundamental rules for operations:**
- Multiplication/Division: Result has the same sig figs as the least precise input
- Addition/Subtraction: Result has the same decimal places as the least precise input

## How to Count and Apply Significant Figures

**Counting examples:**
- 123: 3 sig figs (all non-zero)
- 1.23: 3 sig figs (decimal doesn't change count)
- 0.00123: 3 sig figs (leading zeros don't count)
- 1.230: 4 sig figs (trailing zero after decimal counts)
- 1000: 1 sig fig (ambiguous trailing zeros)
- 1000.: 4 sig figs (decimal indicates precision)
- 1.000 × 10³: 4 sig figs (scientific notation is unambiguous)

**Rounding example:**
Round 0.00456 to 2 sig figs:
First two sig figs are 4 and 5. Next digit is 6 (≥5).
Round up: 0.0046

**Multiplication example:**
8.25 cm × 3.4 cm = 28.05 cm²
8.25 has 3 sig figs; 3.4 has 2 sig figs
Result must have 2 sig figs: 28 cm²

**Addition example:**
12.52 + 1.3 = 13.82
12.52 has 2 decimal places; 1.3 has 1 decimal place
Result must have 1 decimal place: 13.8

## Scenarios People Actually Run Into

**The ambiguous trailing zeros.** "100" could mean 1, 2, or 3 sig figs. Use scientific notation (1.00 × 10²) for clarity.

**The exact number exception.** Counting numbers (12 eggs) and defined values (exactly 1 inch = 2.54 cm) have infinite sig figs.

**The intermediate rounding trap.** Rounding intermediate steps compounds errors. Keep full precision until the final answer.

**The addition versus multiplication confusion.** Different rules apply. Addition uses decimal places; multiplication uses sig figs.

**The calculator display problem.** Calculators show many digits regardless of significance. You must apply sig fig rules manually.

## Trade-Offs and Decisions People Underestimate

**Precision versus accuracy.** Precision is repeatability; accuracy is closeness to truth. Sig figs address precision, not accuracy.

**Over-reporting versus under-reporting.** Too many sig figs implies false precision; too few loses information. Match your measurement capability.

**Scientific notation necessity.** Ambiguous cases require scientific notation for clarity, even when the number could be written otherwise.

**Consistency in reporting.** Within a report, use consistent precision levels for comparable measurements.

**Instrument limitations.** Your result can't be more precise than your least precise measurement instrument.

## Common Mistakes and How to Recover

**Counting leading zeros.** 0.0045 has 2 sig figs, not 4. Leading zeros are placeholders, not significant.

**Forgetting decimal trailing zeros.** 2.50 has 3 sig figs, not 2. The trailing zero after decimal is significant.

**Wrong rule for operation.** Multiplication uses sig figs; addition uses decimal places. Know which rule applies.

**Rounding intermediate steps.** Keep full precision during calculation; round only the final answer.

**Ignoring exact numbers.** Conversion factors and counted quantities have infinite precision and don't limit your result.

## How This Calculator Works

**Counting significant figures:**
```
Remove leading zeros
Count all remaining digits until:
  - End of number (after decimal)
  - Last non-zero digit (before decimal, unless decimal point present)
```

**Rounding to n sig figs:**
```
Identify the nth significant digit
Look at (n+1)th digit
If ≥5: round up nth digit
If &lt;5: keep nth digit
Truncate remaining digits
```

**Multiplication/Division:**
```
Count sig figs in each operand
Result sig figs = minimum of operand sig figs
Round result accordingly
```

**Addition/Subtraction:**
```
Identify decimal places in each operand
Result decimal places = minimum of operand decimal places
Round result accordingly
```

## FAQs

**What counts as a significant figure?**

All non-zero digits, zeros between non-zero digits, and trailing zeros after a decimal point. Leading zeros never count.

**How do I round 0.00456 to 2 sig figs?**

Identify sig figs 4 and 5. Next digit (6) is ≥5, so round up: 0.0046.

**Why does 100 have only 1 sig fig?**

Without a decimal point, trailing zeros are ambiguous. To show 3 sig figs, write 100. or 1.00 × 10².

**Does the calculator handle scientific notation?**

Yes. Enter 6.02e23 or 6.02 × 10^23. Scientific notation preserves sig figs unambiguously.

**What's the rule for addition versus multiplication?**

Addition/subtraction: match least decimal places. Multiplication/division: match least sig figs.

**Can I use this for lab reports?**

Yes. It's designed for proper sig fig handling in scientific contexts requiring precision awareness.

**Why is my answer rounded to fewer digits than expected?**

Your input with the fewest sig figs (or decimal places) determines result precision. This is correct behavior.

**Should I round intermediate steps?**

No. Keep full precision during calculations; round only the final result to prevent cumulative errors.
