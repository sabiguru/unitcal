## How to Use the Percentage Calculator
The **percentage calculator** solves the four most common percentage problems instantly: **“X% of Y,” “X is what percent of Y,” “percent increase/decrease,” and “reverse percentages.”** Simply select the type of calculation, enter your numbers, and get an accurate result with a clear explanation of the formula used. It’s perfect for checking homework, calculating discounts, analysing data, or working out tips—ensuring you never mix up the base value or misapply a formula again.

### Key Formulas Used
- **% of**: `(Percentage / 100) × Base`
- **What %**: `(Part / Whole) × 100`
- **% Change**: `((New – Original) / |Original|) × 100`
- **Reverse %**: `Final / (1 ± Rate)`

### Best Practices for Accurate Results
1.  **Identify the correct base**: In % change, the original value is always the denominator.
2.  **Use positive values for discounts**: Enter 20 for a 20% discount—the calculator handles the subtraction.
3.  **For reverse calculations**, specify whether the final amount includes a markup or reflects a discount.
4.  **Round only the final answer**—keep intermediate steps precise.

## Step-by-Step Example
You’re shopping and see a **£120** jacket with a **25% discount**.

**Step 1**: Select **“X% of Y”** to find the discount amount.  
- Percentage = 25, Base = 120  
- Discount = `(25 / 100) × 120 = £30`

**Step 2**: Subtract to get the sale price: `120 – 30 = £90`

**Alternative**: Use **“Reverse Percentage”** if you only know the sale price.  
- Final price = £90, Discount = 25%  
- Original = `90 / (1 – 0.25) = 90 / 0.75 = £120`

The calculator handles both directions instantly—just choose your scenario.

### How do I calculate a percentage increase?
Use the **% change** function. Enter the original value (e.g., 200) and the new value (e.g., 260). The calculator returns **+30%**, meaning a 30% increase.

### What’s the difference between “percent” and “percentage points”?
If an interest rate rises from 5% to 7%:
- It’s a **2 percentage point** increase.
- It’s a **40% increase** relative to the original (2/5 = 0.4).  
The calculator shows **% change**, not percentage points.

### Can I calculate compound percentages?
This calculator handles **single-step** percentages. For compound changes (e.g., annual interest), apply the calculator sequentially or use a dedicated compound interest tool.

### Why does “20% more than 50” give 60, but “20% of 50” give 10?
- **“20% of 50”** = just the portion (10).
- **“20% more than 50”** = 50 + 10 = 60.  
Use the **% change** function with original=50, new=60 to verify.

### How do I find the original price before VAT?
Use **“Reverse Percentage”** with a **markup**. If the total is £120 and VAT is 20%, the pre-tax price is `120 / 1.20 = £100`.

### Is this calculator accurate for financial planning?
Yes—for basic percentage calculations. For complex financial modelling (e.g., amortisation, compounding), use specialised tools like the [Mortgage Calculator](/calculator/mortgage) or [Compound Interest Calculator](/calculator/compound-interest).

### Can I use negative numbers?
Yes—for % change (e.g., profit/loss). Avoid negatives in “% of” or “what %” unless contextually valid (e.g., temperature changes).
