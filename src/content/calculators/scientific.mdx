## How to Use This Calculator - Scientific
Select your Angle Mode: DEG (degrees) or RAD (radians) for trigonometric calculations.

Enter expressions using standard notation:
- Basic operations: +, -, ×, ÷
- Exponents: xʸ or ^ key
- Scientific notation: EE key (e.g., 6.02 EE 23)
- Functions: sin, cos, tan, log, ln, √, etc.

Use parentheses to control order of operations.

Memory functions: M+ (store), MR (recall), MC (clear memory).

Click = or press Enter to evaluate. Results appear in the display with full precision.

## The Core Principle: Order of Operations

Scientific calculators follow strict mathematical precedence:

1. Parentheses (innermost first)
2. Functions (sin, cos, log, etc.)
3. Exponents (right to left)
4. Multiplication and Division (left to right)
5. Addition and Subtraction (left to right)

**Example:**
3 + 4 × 2² = 3 + 4 × 4 = 3 + 16 = 19
Not (3 + 4) × 2² = 7 × 4 = 28

**Trigonometric functions** evaluate in the selected angle mode:
- DEG: sin(30) = 0.5
- RAD: sin(π/6) = 0.5

The same angle expressed differently gives the same result when the mode matches.

## Scenarios People Actually Run Into

**The angle mode trap.** sin(30) gives -0.988 instead of 0.5. You're in RAD mode. Switch to DEG for degree-based calculations.

**The negative exponent confusion.** 10^-3 should give 0.001. Use the (-) or +/- key for the negative sign, not the subtraction key.

**The scientific notation entry.** Entering 1.6 × 10^-19 as "1.6 × 10 ^ -19" is tedious. Use the EE key: 1.6 EE (-) 19.

**The order of operations surprise.** -3² gives -9, not 9. The calculator evaluates as -(3²). For (-3)², use parentheses.

**The inverse function hunt.** To find arcsin, look for sin⁻¹ or SHIFT+sin, not 1/sin (which is cosecant).

## Trade-Offs and Decisions People Underestimate

**Radians versus degrees.** Mathematics and physics often use radians; engineering and navigation often use degrees. Know your context.

**Precision versus readability.** Full precision shows 0.5000000000001 due to floating-point representation. Round appropriately for your application.

**Memory functions versus parentheses.** Memory stores intermediate results; parentheses show the complete expression. Parentheses are usually clearer.

**Calculator versus manual skill.** Over-reliance on calculators can mask understanding. Practice manual calculations to build intuition.

**Standard versus scientific notation.** Very large or small numbers are more manageable in scientific notation. Switch display modes as needed.

## Common Mistakes and How to Recover

**Wrong angle mode.** Check DEG/RAD before every trigonometric calculation. The single most common scientific calculator error.

**Missing parentheses.** 1/(2+3) is 0.2. 1/2+3 is 3.5. Parentheses clarify intent.

**Inverse function confusion.** sin⁻¹ (arcsin) finds the angle. 1/sin (cosecant) finds the reciprocal of sine. Different operations.

**Scientific notation entry.** Use EE, not "× 10 ^". The EE key handles scientific notation correctly in all operations.

**Negative sign versus subtraction.** Use the negation key ((-) or +/-) for negative numbers, not the subtraction operator.

## How This Calculator Works

**Order of operations (PEMDAS/BODMAS):**
```
1. Evaluate parentheses (innermost first)
2. Evaluate functions (sin, log, √, etc.)
3. Evaluate exponents (right to left)
4. Evaluate multiplication and division (left to right)
5. Evaluate addition and subtraction (left to right)
```

**Trigonometric functions:**
```
if mode == DEG:
  angleRadians = angle × (π / 180)
else:
  angleRadians = angle

sin(angle) = Math.sin(angleRadians)
cos(angle) = Math.cos(angleRadians)
tan(angle) = Math.tan(angleRadians)
```

**Logarithms:**
```
log(x) = log₁₀(x) = Math.log10(x)
ln(x) = logₑ(x) = Math.log(x)
```

**Scientific notation:**
```
a EE b = a × 10^b
Display: mantissa e exponent
```

All calculations happen locally in your browser.

## FAQs

**How do I switch between degrees and radians?**

Click the DEG/RAD toggle. Always verify the mode before trigonometric calculations—wrong mode is the most common error.

**How do I enter scientific notation?**

Use the EE key. For 1.6 × 10⁻¹⁹, press: 1.6 EE (-) 19. Don't type "× 10 ^".

**Why is -3² giving -9 instead of 9?**

The calculator interprets this as -(3²). For (-3)², enter: ( (-) 3 ) x².

**Can I use parentheses?**

Yes—nested parentheses are supported. Use them to ensure expressions evaluate as intended.

**What does the ANS key do?**

It recalls the last result. After calculating 5! = 120, press ANS ÷ 10 to get 12.

**How do I calculate a cube root?**

Enter the value raised to the 1/3 power: 27^(1/3) = 3.

**Is this calculator exam-compliant?**

It mirrors approved physical calculators, but online tools aren't allowed in exams. Use for practice and homework only.

**How do I calculate combinations (nCr)?**

Enter: n nCr r. For "8 choose 3": 8 nCr 3 = 56.

**What's the difference between nCr and nPr?**

nCr (combinations): order doesn't matter (choosing a committee). nPr (permutations): order matters (assigning positions). nPr = nCr × r!

**How do I calculate logarithms of different bases?**

Use the change of base formula: log_b(x) = log(x) / log(b). For log base 2 of 8: log(8) / log(2) = 0.903 / 0.301 = 3.

**What is the natural logarithm (ln)?**

The logarithm with base e (≈2.718). ln(e) = 1, ln(e²) = 2. Natural logs appear throughout calculus and continuous growth models.

**How do I use memory functions effectively?**

M+ adds current display to memory. MR recalls stored value. MC clears memory. Use for intermediate results in multi-step calculations.

**What's the order of inverse trig function ranges?**

arcsin and arctan return values in [-90°, 90°] (or [-π/2, π/2]). arccos returns [0°, 180°] (or [0, π]). Results outside these ranges require adjustment.

**Can I calculate hyperbolic functions?**

Some scientific calculators include sinh, cosh, tanh and their inverses. If not available, use the exponential definitions: sinh(x) = (e^x - e^(-x))/2.

**How do I verify my calculation is correct?**

Work backward: if you calculated sin(30°) = 0.5, verify with arcsin(0.5) = 30°. Dimensional analysis catches many errors in physics calculations.

**What precision should I use for answers?**

Match the precision of your inputs. If inputs have 3 significant figures, report answers to 3 significant figures. More precision implies false accuracy.

**How do I handle very large or very small numbers?**

Use scientific notation. 602,000,000,000,000,000,000,000 is unwieldy; 6.02×10²³ is manageable. The EE key handles this efficiently.

**What is the modulo operation?**

mod gives the remainder after division. 17 mod 5 = 2 (17 = 5×3 + 2). Useful for clock arithmetic, cryptography, and repeating patterns.

**How do I calculate percentage error?**

|(measured - actual) / actual| × 100. This shows how far off a measurement is from the true value, expressed as a percentage.

**Can I program custom functions?**

Most simple scientific calculators don't support programming. For custom functions, use a graphing calculator or computer-based tools like Python or MATLAB.

**What should I do if I get an error message?**

Common errors: division by zero, square root of negative (in real mode), domain errors for inverse trig. Check your input values and mathematical validity.

**Understanding Numerical Precision**

Calculators display many digits, but not all are meaningful. Rounding errors accumulate in long calculations. Floating-point representation can't express some numbers exactly. Report results with appropriate significant figures based on input precision. When results seem slightly off (0.9999999 instead of 1), understand that this is a limitation of numerical representation, not a calculation error.
